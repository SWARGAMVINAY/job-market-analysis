# Job Market Analytics Dashboard

## Project Overview

This project analyzes over 123,000 job postings to identify trends in hiring, experience requirements, work types, locations, and salary distributions.

The objective is to transform raw job market data into meaningful business insights through data cleaning, exploratory data analysis (EDA), and visualization.

## Dataset

* Source: LinkedIn Job Postings Dataset
* Records: 123,849 job postings
* Companies: 24,428
* Locations: 8,526

## Key Analyses

* Experience Level Analysis
* Location Analysis
* Work Type Analysis
* Salary Analysis
* Missing Value Analysis
* Outlier Detection and Removal

## Key Findings

* Mid-Senior level positions dominate the market.
* More than 36,000 entry-level opportunities exist.
* Hiring activity is concentrated in major metropolitan areas.
* Full-time positions represent the majority of job postings.
* Most salaries fall within the $40,000–$120,000 range after outlier removal.
